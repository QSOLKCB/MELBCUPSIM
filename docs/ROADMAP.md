# Roadmap

## v0.1.0 — first playable deterministic Cup
- [x] Original NES-inspired Canvas pixel horses and track, all browser-native
- [x] Replay sourced 2023, 2024 and 2025 Melbourne Cup final orders
- [x] What-if physics with configurable synthetic ternary profile, seed, conditions and strategy
- [x] Pause, resume, speed, single-step, seek, horse-follow and live race desk
- [x] Shareable config URLs, JSON receipts and canonical timeline SHA-256
- [x] Build-free GitHub Pages publishing and pure JS tests

## v0.2.0 — archival depth
- [ ] Extend the validated Cup archive year by year, keeping sources and DNF/dead-heat semantics
- [ ] Add sourced barrier, weight and track condition metadata with explicit missing-value masks
- [ ] Add voluntary import of third-party licensed sectional timing where provenance permits
- [ ] Add a user-facing archive importer with strict schema, versioning and validation

## v0.3.0 — formal experiment
- [ ] Benchmark binary vs balanced ternary vs continuous factors under a fixed information cutoff
- [ ] Distinguish unknown evidence from neutral 0 using a separate observation mask
- [ ] Add GitHub-verifiable pre-race prediction locking, historical holdouts and calibration reports
- [ ] Race engine regression fixtures and stable SHA-256 vectors

## Future art and interaction
- [ ] More expressive retro animation and accessible commentary captions
- [ ] More realistic track schematic (only with source-backed measurements)
- [ ] Local multiplayer sweepstakes with no monetary mechanisms or tracking
- [ ] Offline installability with service-worker version pinning and reproducible caches
